# Image Assets for Hoorfi App

## Directory Structure

```
images/
├── mascot/              # Mascot character expressions
│   ├── mascot_happy.png
│   ├── mascot_excited.png
│   ├── mascot_encouraging.png
│   ├── mascot_celebrating.png
│   └── mascot_neutral.png
├── letters/             # Visual letter cards
│   ├── alif.png
│   ├── ba.png
│   └── ... (all letters)
├── icons/               # UI icons
│   ├── star.png
│   ├── coin.png
│   ├── badge.png
│   ├── lock.png
│   └── unlock.png
├── backgrounds/         # Screen backgrounds
└── illustrations/       # Educational illustrations
```

## Design Guidelines

- Child-friendly, colorful, and inviting
- Mascot should be unique (not Duo-like)
- High resolution (2x, 3x for different devices)
- PNG format with transparency where needed
- Consistent style across all assets
- Bright but not overstimulating colors
- Rounded shapes, soft edges
