# Arabic Fonts for Hoorfi App

## Required Fonts

Please download the Cairo font family from Google Fonts:
https://fonts.google.com/specimen/Cairo

Required files:
- Cairo-Regular.ttf
- Cairo-SemiBold.ttf
- Cairo-Bold.ttf

Place these font files in this directory for proper Arabic text rendering.

Cairo font is chosen for its excellent Arabic letter support and child-friendly readability.
