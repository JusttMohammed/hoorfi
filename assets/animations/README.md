# Animation Assets for Hoorfi App

## Lottie Animations

Place Lottie JSON files here for rich animations:

- `confetti.json` - Celebration confetti animation
- `star_sparkle.json` - Star collection effect
- `mascot_jump.json` - Mascot celebration jump
- `correct_checkmark.json` - Success indicator
- `gentle_wrong.json` - Gentle error feedback
- `loading.json` - Loading animation

## Guidelines

- Export from After Effects or use LottieFiles
- Keep file sizes small (<100KB)
- Optimize for mobile performance
- Test on actual devices
- Ensure smooth 60fps playback
