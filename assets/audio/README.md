# Audio Assets for Hoorfi App

## Directory Structure

```
audio/
├── letters/          # Individual letter pronunciations
│   ├── alif.mp3
│   ├── ba.mp3
│   ├── ta.mp3
│   └── ... (all 28 Arabic letters)
├── words/            # Example words for each letter
├── sounds/           # UI feedback sounds
│   ├── correct.mp3
│   ├── incorrect.mp3
│   ├── celebration.mp3
│   ├── button_tap.mp3
│   └── star_collect.mp3
└── encouragement/    # Mascot voice encouragements
    ├── great_job.mp3
    ├── try_again.mp3
    ├── excellent.mp3
    └── keep_going.mp3
```

## Audio Requirements

- All audio files should be clear, child-friendly Arabic voice
- Letter pronunciations should include proper Tajweed
- Feedback sounds should be pleasant and non-startling
- Format: MP3, 128kbps or higher
- Duration: Letters 1-2 seconds, feedback 0.5-1 second

## Recording Guidelines

- Native Arabic speaker, preferably with experience teaching children
- Clear enunciation with proper makharij
- Warm, friendly tone
- No background noise
